# Online_Library_System

A simple, responsive Online Library System.

GitHub Repository: https://github.com/kartik9699/Online_Library_System

## Features

1. Add Book
2. View Book Details
3. Search Books
4. Categorywise book
5. Books Browsing

## Prerequisites

1. Vite
2. React
3. Node.js
4. NPM
5. Tailwind CSS

## Installation and Project Setup

1. Create a React Project Using Vite
   npm create vite@latest
2. Add Tailwind CSS in React
   npm install tailwindcss @tailwindcss/vite
3. Create Components
   Create modular components for your UI: Header,AddBook,BookCard,BrowseBooks,BookDetails,CategoryCard,Error,Home.
4. Add React-router-DOM for navigation.
   npm i react-router-dom
5. Add react-redux for state management.
   npm install react-redux
   npm install @reduxjs/toolkit
6. Create Utils 
   Create Utils for data and redux:BooksData,Bookslice,category,genreSlice,store.
